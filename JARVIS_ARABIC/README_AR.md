# JARVIS ARABIC — مساعد صوتي عربي مجاني لويندوز 11

برنامج Windows حقيقي (Python + PySide6) بواجهة داكنة سينمائية، يفهم العربية (واللهجة الأردنية) والإنجليزية، ويستجيب بالصوت وينفّذ أوامر على جهازك.

## كل المكوّنات مجانية ومفتوحة المصدر
| الوظيفة | الأداة | ملاحظات |
|---|---|---|
| الكلام ← نص | **faster-whisper** (Whisper) | يعمل محليًا. يحتاج إنترنت **مرة واحدة** لتحميل النموذج (~460MB لـ small) |
| نص ← كلام | **edge-tts** (أصوات مايكروسوفت العصبية، منها الأردنية `ar-JO`) | مجاني بدون مفتاح، **يحتاج إنترنت**. بدون إنترنت يستخدم صوت ويندوز (SAPI) إن وُجد صوت عربي |
| الذكاء الاصطناعي | **Ollama** (اختياري) | محلي بالكامل. للمحادثة والأوامر المعقدة |
| الأوامر الأساسية | قواعد داخلية | سريعة وتعمل بدون إنترنت ولا Ollama |

## التثبيت (خطوة بخطوة)
1. ثبّت **Python 3.11 أو 3.12 (64-bit)** من python.org وفعّل خيار **Add python.exe to PATH**.
2. فك ضغط المشروع، ثم انقر مرتين على **`install.bat`** (ينشئ بيئة ويثبّت المكتبات، يحتاج إنترنت).
3. انقر مرتين على **`run.bat`**. أول تشغيل سيحمّل نموذج الصوت (انتظر رسالة «جاري تحميل النموذج»).
4. اسمح للتطبيق باستخدام المايكروفون: *الإعدادات ← الخصوصية والأمان ← الميكروفون*.
5. **(اختياري) الذكاء الاصطناعي:** ثبّت Ollama من ollama.com ثم في CMD: `ollama pull qwen2.5:3b` (أو `qwen2.5:7b` لجهاز أقوى). سيظهر «AI: Ollama ✔» في التطبيق.

## بناء ملف EXE
- **على جهازك:** بعد `install.bat` شغّل **`build_exe.bat`** ← تجد `dist\JarvisArabic\JarvisArabic.exe` (انسخ المجلد كاملًا؛ لا تنقل الـ exe وحده).
- **بدون تثبيت Python:** ارفع المشروع إلى GitHub وشغّل Workflow باسم `build-exe` (مجاني) ثم نزّل الـ artifact.
- ملاحظة: نموذج Whisper لا يُضمَّن في الـ EXE؛ يُحمَّل لـ `%APPDATA%\JarvisArabic\models` أول مرة.

## الاستخدام
- زر المايك يشغّل/يوقف الاستماع. قل **«يا لونا»** ثم الأمر، أو أطفئ كلمة التنبيه من الإعدادات ليسمع دائمًا.
- بعد ردّه تبقى المحادثة مفتوحة (25 ثانية افتراضيًا) فتكمل بدون تكرار «يا لونا». «مع السلامة» تنهيها.
- يمكنك الكتابة في المربع أسفل اليمين بنفس الأوامر. زر «■ إيقاف الكلام» يقطع نطقه.
- الإغلاق (✕) يخفيه إلى شريط المهام؛ للخروج: أيقونة الشريط ← خروج أو قل «اغلق جارفيس».
- التشغيل مع ويندوز: *الإعدادات ← تشغيل لونا عند بدء ويندوز*.

### أمثلة أوامر
- «افتح كروم / سكّر المفكرة / افتح يوتيوب / افتح موقع example.com»
- «ارفع الصوت / وطّي الصوت شوي / خلي الصوت 30 / اكتم الصوت»
- «شغّل أغنية عمرو دياب» (يبحث في يوتيوب ويفتح أول نتيجة) · «وقف الأغنية / التالية»
- «خذ سكرين شوت» (يُحفظ في Pictures\JARVIS) · «كم الساعة؟ / شو التاريخ؟ / معلومات النظام / كم البطارية؟»
- «ابحث عن طقس عمان / ابحث في يوتيوب عن …» · «اقفل الشاشة»
- «طفي الجهاز / أعد التشغيل» ← يطلب تأكيدًا («نعم») ثم يمهلك 15 ثانية؛ «ألغِ الإطفاء» للتراجع.
- أي شيء آخر («اشرح لي…»، «بدي أفتح البرنامج الفلاني وأرفع الصوت») يذهب إلى Ollama.
- برامج غير معروفة: أضفها من الإعدادات ← «برامج مخصصة» بصيغة `اسم = C:\مسار\برنامج.exe`.

## حل المشاكل
| المشكلة | الحل |
|---|---|
| لا يلتقط صوتي | اختر المايك من الإعدادات؛ تأكد من إذن الميكروفون؛ خفّض «عتبة الصوت» |
| لا يتعرف على «يا لونا» | اكتب صيغة ظهرت في سطر «سمعتُ: …» ضمن كلمات التنبيه، أو جرّب نموذج `medium` |
| الرد بطيء | استخدم نموذج `base`، أو `qwen2.5:1.5b` في Ollama |
| لا ينطق | edge-tts يحتاج إنترنت؛ ثبّت حزمة لغة عربية للكلام في ويندوز كبديل |
| أي خطأ | راجع `%APPDATA%\JarvisArabic\jarvis.log` |

## هيكل المشروع
`main.py` نقطة التشغيل · `jarvis/nlu.py` فهم الأوامر · `jarvis/actions.py` أوامر ويندوز · `jarvis/llm.py` Ollama · `jarvis/stt.py`/`vad.py`/`listener.py` الاستماع · `jarvis/tts.py` النطق · `jarvis/assistant.py` المنسّق · `jarvis/ui/` الواجهة · `tests/` الاختبارات (`pip install -r requirements-dev.txt` ثم `pytest`).

## ما تم اختباره وما لم يُختبر
تم اختباره آليًا (115 اختبارًا): فهم الأوامر عربي/إنجليزي، كلمة التنبيه، كشف الكلام، الإعدادات، منطق الأوامر بمحاكاة ويندوز، تدفق المحادثة والتأكيد، عميل Ollama (خادم وهمي)، والواجهة.
**لم يُختبر لأن بيئة البناء ليست ويندوز ولا فيها مايك/إنترنت مفتوح:** التشغيل الفعلي على ويندوز 11 (taskkill، pycaw، السجل)، التقاط المايك الحقيقي ودقة Whisper على لهجتك، أصوات edge-tts، وبناء PyInstaller. إن ظهر خطأ أرسل لي محتوى `jarvis.log` وسأصلحه.
